# UMarketplace
**is a student buy and sell platform designed for students of University of Mindanao. It provides a centralized marketplace where students can buy and sell their items such as, school supplies, uniforms, books, and other useful items within the university. The system aims to make school materials more affordable while allowing students to sell their (but not limited to) used or unused belongings to other students.**

# Main Features (initial progress)
‣ Access to Login and HomePage menu.

‣ Item categories - Organizes listing (e.g., Books, Uniforms, School Supplies, Electronics, Others).

‣ Browse + Search and Filter - Allows students to view all active listings and filter items by category and price.

‣ Contact Seller - Allows students to view listing details and see seller’s contact info or a contact seller form. (No in-app payment, cart or checkout. Transactions happen offline).

# How To Run:
1. Download the UMarketplace project repository from GitHub.
2. Open the project folder using your preferred IDE.
3. Make sure the required programming language, libraries, and dependencies are installed.
4. All image and text assets (UMarketplaceHome.jpg, HelveticaNowDisplay-Regular.ttf etc.) remain in the root directory alongside the source code.
5. Run Main.java as a Java Application.

NOTE: This is an initial progress of the project, the login accepts any input and you are able to freely access the home page. Current data were seeded.
