# UMarketplace
**is a student buy and sell platform designed for students of University of Mindanao. It provides a centralized marketplace where students can buy and sell their items such as, school supplies, uniforms, books, and other useful items within the university. The system aims to make school materials more affordable while allowing students to sell their (but not limited to) used or unused belongings to other students.**

# Main Features (initial progress)
‣ Access to Login and HomePage menu.

‣ Item categories - Organizes listing (e.g., Books, Uniforms, School Supplies, Electronics, Others).

‣ Browse + Search and Filter - Allows students to view all active listings and filter items by category and price.

‣ Contact Seller - Allows students to view listing details and see seller’s contact info or a contact seller form. (No in-app payment, cart or checkout. Transactions happen offline).

# How To Run:
1. Download or clone the **UMarketplace** repository from GitHub (`<> Code` → `Download ZIP`, then extract).

3. Make sure **Java Development Kit (JDK) 21** (or compatible Java SE) is installed. No external third-party libraries are required (uses built-in Java Swing).

5. Open the extracted project folder in your preferred IDE:
   - **Eclipse:** Go to `File` → `Open Projects from File System...` and select the extracted folder (ensure `src` is configured as the source folder).
   - **IntelliJ IDEA / VS Code:** Open the extracted root folder directly.

6. Keep all image and font files (`UMarketplace.jpg`, `UMarketplaceHome.jpg`, `ListingCardPanel.png`, `HelveticaNowDisplay-Regular.ttf`, `HelveticaNowDisplay-Bold.ttf`, and etc.) in the **project root directory** alongside `src/`.

8. Locate **`src/umarketplace/Main.java`** and run it as a **Java Application**.

> **NOTE:** This is an initial progress build of the project—the login screen accepts any input so you can freely access the home page, and current listings are seeded sample data.
