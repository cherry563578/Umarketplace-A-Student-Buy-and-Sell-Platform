UMarketplace is a student buy and sell platform designed for students of University of Mindanao. It provides a centralized marketplace where students can buy and sell their items such as, school supplies, uniforms, books, and other useful items within the university. The system aims to make school materials more affordable while allowing students to sell their unused belongings to other students.

MAIN FEATURES
User Registration and Login - Allows students to create accounts and log in to access the marketplace.
User Profiles - Allows students to view, and edit their own profile and view other students' public information (name, course, contact details).
Item Listings - Enable students to create, edit and delete their listings which contains: title, description, category, price, status, and photo.
Item categories - Organizes listing (e.g., Books, Uniforms, School Supplies, Electronics, Others).
Browse + Search and Filter - Allows students to view all active listings and filter items by category and price.
Contact Seller - Allows students to view listing details and see seller’s contact info or a contact seller form. (No in-app payment, cart or checkout. Transactions happen offline). 
Listing Status - Sellers can mark a listing as Available/ Reserved/ Sold. 
Admin Panel - Allows admin to view all users, activate or deactivate them and view all listings, remove/ hide inappropriate or misleading posts. 





INSTRUCTIONS ON HOW TO RUN THE PROJECT

Download the UMarketplace project repository from GitHub.
Open the project folder using your preferred IDE.
Make sure the required programming language, libraries, and dependencies are installed.
Configure the database or other required files, if applicable.
Run the main program file.
Register a student account or log in using an existing account.
Start browsing, searching, and managing item listings.
